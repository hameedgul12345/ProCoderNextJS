Main detail + easy example ke saath samjhata hoon:

# ⚡ Incremental Static Regeneration (ISR) in Next.js

### **Definition**

ISR ek **improvement over SSG** hai.

* Normal **SSG** me → page ek baar **build ke waqt** generate hota hai aur fir kabhi update nahi hota (jab tak tum poora project rebuild na karo).
* **ISR** allow karta hai ki tumhare static pages **build ke baad bhi regenerate/update** ho sake — bina puri app ko rebuild kiye.

---

# ⚙️ How it Works

1. Jab user page visit karta hai:

   * Agar page cache me available hai aur fresh hai → wohi serve hota hai.
   * Agar page cache expire ho gaya (revalidate time khatam), to ek **naya page background me regenerate** hota hai.

2. Users hamesha fast static content dekhte hain, aur updated data automatically agle requests ke liye ready hota hai.

---

# 📌 Example (Next.js)

```js
// pages/blog/[id].js
export async function getStaticProps({ params }) {
  const res = await fetch(`https://api.example.com/posts/${params.id}`);
  const post = await res.json();

  return {
    props: { post },
    // Revalidate after 10 seconds
    revalidate: 10,
  };
}

export async function getStaticPaths() {
  return {
    paths: [{ params: { id: "1" } }],
    fallback: "blocking",
  };
}
```

👉 Yahan `revalidate: 10` ka matlab:

* Page banne ke baad 10 second tak cache valid rahega.
* 10s ke baad koi user visit karega → Next.js background me **fresh version generate** karega.
* Next request se updated page milega.

---

# ✅ Benefits of ISR

* 🔥 **Best of Both Worlds** → Static speed + Dynamic updates
* ⚡ **Fast delivery** (CDN se static HTML serve hota hai)
* 🔄 **Up-to-date data** bina redeploy/rebuild kare
* 💰 **Cost-efficient** → Sab pages ek sath build karne ki zarurat nahi

---

# 🆚 ISR vs SSG

| Feature    | SSG                            | ISR                                       |
| ---------- | ------------------------------ | ----------------------------------------- |
| Build time | Sab pages ek hi baar ban jaate | Pages background me regenerate hote rehte |
| Updates    | Sirf rebuild ke time           | Auto updates with `revalidate`            |
| Use case   | Blogs, docs (rarely change)    | E-commerce, news (frequently change)      |

---

👉 Short me: **ISR = SSG + Auto Refresh Mechanism** 🚀
